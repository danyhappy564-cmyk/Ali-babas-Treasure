[제목] [SPT 4.1] 알리바바의 보물 v1.5.0 — 플리마켓 전용 만능 열쇠·키카드·연구소/래버린스 출입증

열려라, 참깨!

플리마켓에서만 파는 "만능 열쇠" 5종을 추가하는 SPT 4.1용 모드입니다.
열쇠 찾으러 다니는 게 귀찮을 때, 대신 비싸게 사서 쓰는 용도로 만들었습니다.

- AlibabaTreasure-Client-1.5.0.zip (클라)

■ 대상
SPT 4.1.5 이상 (4.1.x)

■ 아이템 (기본 가격 / 기본 횟수)
1. 알리바바의 키카드 — 5,000,000₽ / 10회
 · 카드 리더 달린 모든 문 + 키카드가 필요한 탈출구
 · 모델: 인터체인지 Object #11SR 카드

2. 알리바바의 열쇠 — 3,000,000₽ / 10회
 · 마크방을 뺀 모든 기계식 자물쇠 (문, 차 트렁크, 잠긴 상자, 스위치) + 열쇠가 필요한 탈출구
 · 모델: 키바 암스 외부 문 열쇠

3. 알리바바의 마크방 열쇠 — 8,000,000₽ / 10회
 · 마크방만 (세관 기숙사 314, 리저브 RB-BK·RB-VO·RB-PKPM, 등대 공용 침실, 시내 버려진 공장·수상한 방)
 · 모델: 기숙사 314 마크 열쇠

4. 알리바바의 연구소 출입증 — 2,000,000₽ / 10회
 · 연구소 입장 (들어갈 때마다 1회 차감, 문은 못 엶)
 · 모델: 랩스 검은 키카드

5. 알리바바의 래버린스 출입증 — 1,500,000₽ / 10회
 · 래버린스 입장 (들어갈 때마다 1회 차감, 문은 못 엶)
 · 모델: 래브리스 출입 카드

게임에 있는 모델을 그대로 써서 따로 받을 번들 파일은 없습니다.

■ 특징
- WTT-Backport 같은 모드가 추가한 열쇠·키카드 문도 자동으로 열립니다.
  "그 문이 원래 요구하는 열쇠가 키카드인지, 마크 열쇠인지, 일반 열쇠인지"로 판단해서 따로 목록이 필요 없습니다.
- 진짜 열쇠를 같이 갖고 있으면 진짜 열쇠를 먼저 씁니다. 알리바바 아이템 횟수는 다른 방법이 없을 때만 줄어듭니다.
- 툴팁에 남은 횟수가 바로 보입니다 (출입증은 "남은 입장 횟수 3/10회").
- 기본값으로는 플리마켓 말고 어디서도 안 나옵니다.
  맵 바닥·컨테이너(마크방 포함)·봇 등장 확률이 기본 0%이고,
  펜스·에어드랍·스캐브 케이스·PMC 루트에는 설정과 관계없이 항상 안 나옵니다.

■ F12 설정 (Ali Baba's Treasure)
- 맨 위 "00. Language · 언어"에서 한국어 / English 전환 (바꾼 뒤 F12 창을 닫았다 다시 열기)
- 아이템마다 조절 가능:
  플리마켓 가격 (1만 ~ 5천만₽) / 사용 횟수 (1 ~ 100) / 무제한 사용 / 맵 바닥·컨테이너·봇 등장 확률 (0 ~ 100%, 0.1 단위)
- "모든 등장 확률 0으로" 버튼, "디버그 모드" (문제 제보용 로그)
- 설정은 서버에 저장돼서 재시작해도 유지됩니다.

■ 등장 확률을 켜고 싶은 분께
LotsofLoot 모드처럼 맵 루트 테이블에 넣는 방식입니다.
열쇠·키카드가 원래 나오는 자리(바닥 열쇠 자리, 재킷·서랍·더플백·죽은 스캐브 등)에만 들어가고,
확률은 "그 자리에서 한 번 뽑을 때 이 아이템이 나올 확률"입니다. LotsofLoot와 같이 써도 충돌하지 않습니다.

대략 이 정도 나옵니다 (기본 맵 데이터 기준, 아이템 1종, 한 판 평균):
- 세관: 바닥 1% → 11판에 1개 / 컨테이너 0.1% → 9판에 1개
- 리저브: 바닥 1% → 20판에 1개 / 컨테이너 0.1% → 3판에 1개
- 시내: 바닥 1% → 7판에 1개 / 컨테이너 0.1% → 2판에 1개
컨테이너는 0.1%만 해도 꽤 자주 나오니 낮게 잡는 걸 추천합니다.
봇은 봇 한 명마다 굴려서 1%만 해도 자주 보입니다. LotsofLoot를 쓰면 위 숫자보다 더 나옵니다.
