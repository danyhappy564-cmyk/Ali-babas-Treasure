## 한국어

플리마켓에서만 파는 "만능 열쇠" 5종을 추가합니다. 모델은 게임에 있는 것을 그대로 써서 번들 파일이 없습니다.

| 아이템 | 하는 일 | 모델 | 기본 가격 / 횟수 |
|---|---|---|---|
| 알리바바의 키카드 | 카드 리더가 달린 모든 문, 키카드 탈출구 | 인터체인지 Object #11SR | 5,000,000₽ / 10회 |
| 알리바바의 열쇠 | **마크방을 뺀** 모든 기계식 자물쇠(문·트렁크·상자·스위치), 열쇠 탈출구 | 키바 암스 외부 문 열쇠 | 3,000,000₽ / 10회 |
| 알리바바의 마크방 열쇠 | **마크방만** (세관 314, 리저브 RB-BK·RB-VO·RB-PKPM, 등대, 시내) | 기숙사 314 마크 열쇠 | 8,000,000₽ / 10회 |
| 알리바바의 연구소 출입증 | **연구소 입장** (입장마다 1회 차감, 문은 못 엶) | 랩스 검은 키카드 | 2,000,000₽ / 10회 |
| 알리바바의 래버린스 출입증 | **래버린스 입장** (입장마다 1회 차감, 문은 못 엶) | 래브리스 출입 카드 | 1,500,000₽ / 10회 |

### 특징
- **모드 열쇠도 자동 지원** — "그 잠금이 원래 요구하는 열쇠의 종류"로 판단하므로 WTT-Backport 등이 추가한 열쇠·키카드 문도 따로 목록 없이 열립니다. 영어 이름에 "marked"가 들어간 모드 열쇠는 마크방 열쇠 쪽으로 분류합니다.
- **진짜 열쇠가 먼저** — 진짜 열쇠를 같이 갖고 있으면 그걸 먼저 쓰고, 알리바바 아이템 횟수는 다른 방법이 없을 때만 줄어듭니다.
- **사용 횟수 차감·소멸은 게임 원래 코드가 처리** — 문 열기 순간에만 잠금이 요구하는 ID를 잠깐 바꿨다 되돌리는 방식입니다.
- **툴팁에 남은 횟수 실시간 표시** — 출입증은 "남은 입장 횟수 3/10회".
- **기본적으로 어디서도 공짜로 안 나옴** — 맵 바닥·컨테이너(마크방 포함)·봇 등장 확률 기본 0%. 펜스·에어드랍·스캐브 케이스·PMC 루트에는 확률과 관계없이 항상 안 나옵니다.

### F12 설정 (`Ali Baba's Treasure`)
- 맨 위 **`00. Language · 언어`** 에서 한국어 / English 전환 (자동 = 윈도우 언어). 바꾼 뒤 F12 창을 닫았다 다시 열면 적용됩니다.
- 아이템마다: 플리마켓 가격(1만~5천만₽) · 사용 횟수(1~100) · 무제한 · 맵 바닥 / 컨테이너 / 봇 등장 확률(0~100%, 0.1 단위).
- **모든 등장 확률 0으로** 버튼, **디버그 모드**(문제 제보용 로그).
- 설정은 서버 `config\config.json`에 저장되어 재시작 후에도 유지됩니다.

### 등장 확률의 뜻 (LotsofLoot 방식)
맵 루트 테이블 중 **열쇠·키카드가 원래 나오는 곳에만** 가중치로 넣습니다. 확률 = 그 자리에서 한 번 뽑을 때 이 아이템이 나올 확률입니다.
LotsofLoot와 같이 써도 충돌하지 않습니다(LotsofLoot의 루트 배수가 그대로 곱해집니다).

| 맵 (한 판 기대값, 1종 기준) | 바닥 0.1% | 바닥 1% | 컨테이너 0.1% | 컨테이너 1% |
|---|---|---|---|---|
| 세관 | 100판에 1개 | 11판에 1개 | 9판에 1개 | 한 판 1.1개 |
| 리저브 | 100판에 1개 | 20판에 1개 | 3판에 1개 | 한 판 3.7개 |
| 시내 | 100판에 1개 | 7판에 1개 | 2판에 1개 | 한 판 6.5개 |

컨테이너가 바닥보다 훨씬 자주 나옵니다. 봇은 봇 1명당 굴림이라 1%만 해도 자주 보입니다.

### 설치
1. 두 zip을 `SPT 4.1` 폴더에 그대로 풉니다.
2. 서버 로그에 `[AlibabaTreasure] registered 5 item(s)`가 보이면 정상입니다.
3. 플리마켓은 SPT 기본 설정상 레벨 15부터 열립니다.

### 알려진 점
- 출입증의 사용 횟수를 F12에서 **이미 쓴 횟수보다 낮게** 줄이면, 그 출입증은 입장으로는 사라지지 않습니다(게임의 입장 차감이 "정확히 같을 때만" 지우는 방식).
- 탈출 조건 자체가 "열쇠 소지"인 탈출구는 몇 곳인지 확인하지 못했습니다. 있으면 통과되도록 처리했습니다.
- **모드를 지우기 전에** 창고의 알리바바 아이템을 팔거나 버리세요. 없는 아이템이 프로필에 남으면 SPT가 프로필을 못 읽을 수 있습니다.
- 버그 제보는 F12 디버그 모드를 켠 뒤 `BepInEx/LogOutput.log`와 서버 로그를 같이 보내 주세요. **원작자(TheBoogle, ArchangelWTF)에게 이 모드 문제를 문의하지 마세요.**

## English

Adds five flea-market-only "master keys". They reuse models already in the game, so there are no bundle files.

| Item | What it does | Model | Default price / uses |
|---|---|---|---|
| Ali Baba's Keycard | Every card-reader door, keycard extracts | Interchange Object #11SR | 5,000,000₽ / 10 |
| Ali Baba's Key | Every mechanical lock **except marked rooms** (doors, trunks, locked boxes, switches), key extracts | Kiba Arms outer door key | 3,000,000₽ / 10 |
| Ali Baba's Marked Key | **Marked rooms only** (Customs 314, Reserve RB-BK/RB-VO/RB-PKPM, Lighthouse, Streets) | Dorm room 314 marked key | 8,000,000₽ / 10 |
| Ali Baba's Labs Pass | **Labs entry** (one use per raid, opens no doors) | Labs black keycard | 2,000,000₽ / 10 |
| Ali Baba's Labyrinth Pass | **Labyrinth entry** (one use per raid, opens no doors) | Labrys access keycard | 1,500,000₽ / 10 |

### Highlights
- **Modded keys just work** — the lock's own key type decides which treasure opens it, so doors from mods such as WTT-Backport need no list. Modded keys with "marked" in their English name count as marked-room keys.
- **Real keys go first** — a treasure use is spent only when you have nothing else that fits.
- **Use counting and removal are done by the game itself** — the lock's required ID is swapped only for the moment of the check.
- **Live tooltip** — remaining uses (passes show "Entries left 3/10").
- **Never free by default** — floor, container (marked rooms included) and bot chances default to 0%. Fence, airdrops, scav case and PMC loot never give them, whatever the chance.

### F12 settings (`Ali Baba's Treasure`)
- **`00. Language · 언어`** at the top switches Korean / English (Auto = Windows language). Close and reopen F12 after switching.
- Per item: flea price (10k–50M₽), uses (1–100), unlimited, floor / container / bot spawn chance (0–100%, 0.1 steps).
- **Reset spawn chances** button and **Debug mode** (logs for bug reports).
- Saved on the server in `config\config.json`, kept across restarts.

### What the spawn chance means (LotsofLoot style)
Treasures are added as weighted entries **only to loot pools that already hold keys or keycards**. The chance is the share of each such draw. Works alongside LotsofLoot (its multipliers apply on top).

| Map (expected per raid, one item) | Floor 0.1% | Floor 1% | Container 0.1% | Container 1% |
|---|---|---|---|---|
| Customs | 1 in 100 raids | 1 in 11 | 1 in 9 | 1.1 per raid |
| Reserve | 1 in 100 raids | 1 in 20 | 1 in 3 | 3.7 per raid |
| Streets | 1 in 100 raids | 1 in 7 | 1 in 2 | 6.5 per raid |

Containers turn them up far more often than the floor. Bots roll once per bot, so even 1% shows up often.

### Install
1. Extract both zips into your `SPT 4.1` folder.
2. The server log should show `[AlibabaTreasure] registered 5 item(s)`.
3. The flea market opens at level 15 by SPT default.

### Known notes
- Lowering a pass's uses in F12 **below what it has already used** keeps that pass from being removed on raid entry (the game's entry check removes it only on an exact match).
- I could not confirm how many extracts require *carrying* a key; any that do are handled.
- **Before uninstalling**, sell or discard your treasures. Items left in the profile without the mod can stop SPT from loading it.
- For bug reports, turn on F12 Debug mode and send `BepInEx/LogOutput.log` plus the server log. **Please do not contact TheBoogle or ArchangelWTF about this mod.**
